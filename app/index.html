      Methodology

      How a location reaches the shortlist

      Every number is computed by deterministic code from public data. The investigation layer explains results; it never chooses sites.

        The deterministic system makes the decision. Investigation explains and questions it, and never changes it.

          Limitations

          What this does not establish

          • Grid connection capacityNearby mapped lines and substations are grid evidence, not capacity.
          • Land availabilityWhether a plot can be leased or used is not in public data.
          • PermitsDistrict and national permit requirements are not assessed.
          • Host / owner willingnessNo site host or landowner has been contacted.
          • Commercial viabilityNo tariffs, costs, revenue or payback are modelled.
          • Actual utilizationCoverage is modelled population, not charging sessions.

          These require operator, utility, site-owner or field verification.
